## Why

首版需要让开发者从干净检出开始，登录 Web 工作台并在随项目发布的 Maven 测试报告中找到已知的失败位置。当前启动会初始化知识检索依赖，仓库里也缺少带预期结果的公开报告，难以用同一份输入检验后续诊断。

## What Changes

- 提供可显式关闭知识库的基础模式，从现有登录入口进入报告视图。启用知识库的既有部署继续使用原有问答链路。
- 登记一个公开示例工作区，随仓库提供小型 Maven 项目、已生成的 Surefire XML、报告生成方法和预期失败位置。
- 登录用户可只读查看其获准访问的报告，核对来源、测试类、方法和报告记录的异常。提供从干净检出到浏览器核对结果的启动说明。

## Capabilities

### New Capabilities

- `diagnostics-baseline` — 关闭知识库时启动工作台，并在用户可访问的示例工作区中复现测试失败位置。

### Modified Capabilities

## Impact

影响 Vue 工作台入口、Spring Boot 装配、测试报告读取及公开示例与启动文档。沿用现有身份与基础存储。模型诊断与知识引用、草稿确认与写工单、公开评测分别留给后续里程碑。

方案依据见[首版整体方案的里程碑](../../../resources/markdown/Eevee-Agent自托管工作台首版方案.md#里程碑与交付证据)。
