## Purpose

让首次检出项目的开发者在知识库关闭时登录工作台，读取公开样例中已经生成的测试报告，并在浏览器中将失败位置与预期结果逐项核对，为后续的诊断能力提供可复现的基线。

## ADDED Requirements

### Requirement: 基础模式独立启动

系统 SHALL 提供显式关闭知识库的启动方式。在满足文档列明的基础依赖后，用户可以登录工作台并使用报告入口。

#### Scenario: 从干净检出进入工作台

- **WHEN** 开发者从新检出的仓库按说明准备独立的本地基础依赖，关闭知识库，并在 Milvus 和知识库对象存储未运行时启动前后端
- **THEN** 开发者可以通过现有登录流程在浏览器中打开报告入口并选中获准访问的公开示例

#### Scenario: 既有部署继续启用知识库

- **WHEN** 使用原有配置、具备知识库依赖的部署升级，未显式选择关闭知识库
- **THEN** 登录用户仍可从原入口发起知识库问答

### Requirement: 可复现的公开失败样例

仓库 SHALL 提供可公开分发的小型 Maven 项目、预生成的 Surefire XML、预期失败位置及重新生成报告的说明，并使首次阅读独立于本机历史构建产物。

#### Scenario: 新检出直接核对样例

- **WHEN** 开发者尚未构建样例，在工作台中打开随仓库发布的报告
- **THEN** 可直接读取报告，并与样例说明列出的测试类、方法和失败类型逐项比对

#### Scenario: 重新生成并核对失败位置

- **WHEN** 开发者在样例目录独立运行文档给出的测试命令
- **THEN** 测试按预期失败并生成 Surefire 报告，失败的测试类、方法和失败类型与随仓库发布的样例一致

### Requirement: 限定工作区并只读展示报告事实

系统 SHALL 仅向已登录且有权访问所选工作区的用户返回报告事实，包括报告的工作区相对来源、失败测试类、方法和报告中实际记录的失败或异常信息。

#### Scenario: 读取已登记的失败报告

- **WHEN** 获准访问的用户在知识库关闭时读取有效的失败样例
- **THEN** 工作台显示来源、失败测试类、方法及 XML 记载的失败类型和可用消息，读取过程无需调用模型，也不触发 Maven 构建或创建工单

#### Scenario: 请求超出可读范围

- **WHEN** 请求缺少有效登录身份，或目标报告不在该用户获准读取的已登记工作区内
- **THEN** 系统拒绝读取，不返回报告正文或服务器绝对路径

#### Scenario: 缺失或损坏的报告

- **WHEN** 获准访问的报告缺失，或 XML 无法解析
- **THEN** 工作台提示相应的读取或解析问题，不把该次读取显示为测试通过，也不生成推测的失败位置
